## 6. Recomendaciones meta

1. **Automatizar reconciliación**: agregar script `scripts/audit-counts.sh` que se ejecute en pre-commit y actualice tabla del README automáticamente. Evita futuros desfases.
2. **Plantilla de "definition of done" por vertical**: las cifras crudas (skills, evals) no reflejan calidad. Score honesto requiere checklist específico.
3. **Bilingüismo frontmatter**: muchos skills tienen description 100% ES. Agregar sinónimos EN para triggering robusto desde usuarios anglófonos.
4. **Discoverability index**: 307 skills dispersos → considerar `docs/skills-index.md` autogenerado con búsqueda por keyword.
5. **No invertir en MCPs bloqueados**: SAT/bancos/IMSS sin partnership no son viables como scraper. Aceptar dependencia humana.
