# wedding-mx

Plugin para wedding planners y proveedores de bodas en México.

## Casos de uso

- **Wedding planner full-service** (coordina todo el evento)
- **Wedding planner day-of** (solo coordina el día del evento)
- **Proveedores individuales**: banquete, hacienda, decoración, música, video
- **Haciendas-de-eventos** con paquetes todo-incluido
- **Bodas de destino** (Cancún, Tulum, San Miguel, Sayulita)

## Skills propios (5)

| Skill | Cuándo activa |
|---|---|
| `cotizacion-boda-mxn` | Cotización detallada por capítulos (banquete, alquiler, deco…) |
| `timeline-evento` | Cronograma D-90 a D+30 con hitos críticos |
| `proveedores-bda` | Gestión proveedores con presupuesto vs gastado |
| `novios-onboarding` | Captura inicial de novios + datos fiscales |
| `contrato-boda-pf-pm` | Contrato de servicios con cláusulas anti-cancelación |

## Comandos

```
/wedding:cotizar-boda
/wedding:timeline-boda
/wedding:onboarding-novios
/wedding:contrato-evento
```
