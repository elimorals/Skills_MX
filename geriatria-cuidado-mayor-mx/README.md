# geriatria-cuidado-mayor-mx

Plugin para residencias de adultos mayores, day-care geriátrico, cuidadores a domicilio y familias mexicanas cuidando ancianos en casa. Score research: **7.5/10**, mercado: ~15M adultos 65+ en MX (proyección 2050: 32M). Construido sobre `core-mexico` + `paciente-mx`.

## Skills propios (5)

| Skill | Propósito |
|---|---|
| `expediente-geriatrico` | NOM-167/031 + escalas funcionales Barthel/Lawton/MMSE/Tinetti |
| `tracking-medicamentos-vencimiento` | Polifarmacia + adherencia + interacciones críticas |
| `agenda-cuidadores` | Turnos 24h con CFDI Nómina + plus nocturno/dominical |
| `comunicacion-familiar-distribuida` | Sincroniza hijos en varias ciudades + log decisiones |
| `gestor-tramites-pension` | IMSS Ley 73 vs 97, ISSSTE, Bienestar federal, AFORE |

## Compliance crítico

- NOM-167-SSA1 (asistencia social adultos mayores)
- NOM-031-SSA3 (residencias)
- LFT Art. 67 (nocturno), 71 (dominical), 74-75 (festivos)
- IMSS empleadas del hogar (régimen especial)
- LFPDPPP datos sensibles + capacidad jurídica (poder notarial)
