# educacion-particular-b2c-mx

Plugin para creadores de cursos online B2C en México (tutores, academias, bootcamps, coaches). Inscripción alumnos, CFDI mensual G03 (o D10 con IEDU si RVOE), cobranza recurrente, tracking progreso, certificados PDF. Score 7.5/10. Mercado: 80k creadores.

## Skills

1. `dashboard-academia-online`
2. `inscripcion-alumno-curso`
3. `cfdi-mensualidad-curso`
4. `cobranza-recurrente-cursos`
5. `emision-certificado-pdf`

- `/educacion:dashboard`
