# mp_concilianet_profeco

Conciliación digital PROFECO con 32 proveedores en convenio.

## Tools

- `concilianet_consultar_proveedor(razon_social)` — tiene convenio: bool.
- `concilianet_estatus_caso(folio)` — fase + audiencia.
- `concilianet_listar_proveedores()` — 32 conveniados 2026.
- `concilianet_registrar_queja(proveedor, descripcion, monto_reclamado_mxn?)`.
