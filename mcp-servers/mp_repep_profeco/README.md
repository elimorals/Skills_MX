# mp_repep_profeco

Registro Público para Evitar Publicidad (REPEP) — PROFECO.

**Universo**: call centers + outbound telemarketing MX.

## Tools

- `repep_consultar(telefono)` — inscrito: bool.
- `repep_filtrar_lote(telefonos[])` — separa contactables vs bloqueados.
- `repep_inscribir(telefono, propietario_curp?)` — inscribir nueva línea.
- `repep_estadisticas()` — universo agregado.
