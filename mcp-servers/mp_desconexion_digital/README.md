# mp_desconexion_digital

Reforma LFT Art. 132 marzo 2026 — desconexión digital obligatoria.

**Universo**: ~4M empresas formales con trabajadores.

## Tools

- `desconexion_checklist(rfc, faltas_marcadas?)` — score + 8 ítems.
- `desconexion_generar_politica(rfc, razon_social, jornada_inicio?, jornada_fin?, canal_denuncia_email?)` — Markdown firmable.
- `desconexion_template_capacitacion()` — agenda 45 min para mandos.
