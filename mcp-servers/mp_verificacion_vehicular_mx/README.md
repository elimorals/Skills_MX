# mp_verificacion_vehicular_mx

Verificación vehicular obligatoria — 7 estados (CDMX, EdoMex, HGO, MOR, PUE, TLAX, JAL).

## Tools

- `verificacion_consultar_estatus(placa, estado)` — holograma + vigencia.
- `verificacion_proximo_periodo(placa)` — color engomado + mes obligatorio.
- `verificacion_listar_programas()` — los 7 programas.
