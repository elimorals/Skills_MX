# mp_catastro_estatal_mx

Consulta valor catastral en sistemas estatales: IGECEM (EdoMex, 125 muns),
IRCEP (Puebla, 217 muns), Veracruz (212), QRoo, Yucatán.

## Tools

- `catastro_consultar_valor(sistema, cuenta_catastral)` — valor + superficie + uso suelo.
- `catastro_listar_sistemas()` — los 5 sistemas del catálogo.
