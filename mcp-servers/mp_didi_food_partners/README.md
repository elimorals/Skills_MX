# mp_didi_food_partners

MCP para restaurantes en DiDi Food MX. Mock-first hasta tener credenciales Partner.

## Setup real (humano)

1. Aplicar como restaurante en DiDi Food
2. Solicitar acceso API Partner via tu account manager
3. Setear `DIDI_FOOD_TOKEN` + `DIDI_FOOD_RESTAURANT_ID`
4. Implementar `client.py` real (HTTP requests)

## Tools

6 tools idénticos en estructura a `mp_rappi_partners`: listar/consultar órdenes, menú, disponibilidad, ranking, comisiones (~30%).
