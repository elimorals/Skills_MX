01

Qué hace, en una frase.

"Pasa tu cartera de propiedades. Recibe el adeudo de las que se pueden consultar en línea y la ruta manual de las demás, en un CSV."
02

Tools expuestas.

4 tools MCP invocables desde Claude Code (o cualquier cliente MCP), o como librería Python (predial_mx_client).

→

predial_consultar

Consulta adeudo de una propiedad. Auto-routing por catálogo. Donde el portal tiene CAPTCHA devuelve entrega a humano.

predial_consultar(estado, municipio, cuenta_predial, [tipo, direccion])
→

predial_listar_municipios

Lista municipios del catálogo. Filtro opcional por estado o por solo_validados=True.

predial_listar_municipios([estado], [solo_validados])
→

predial_buscar_municipio

Busca municipio por nombre fuzzy. Devuelve mejores coincidencias con su configuración.

predial_buscar_municipio(query)
→

predial_estadisticas_catalogo

Devuelve stats del catálogo (total muns, validados, con captcha, plataformas SaaS detectadas).

predial_estadisticas_catalogo()

04

Cómo se ve el código.

cartera_predial.py · clients/predial_mx_client 
from predial_mx_client import PredialMxClient, CaptchaRequeridoError

cliente = PredialMxClient()

# Tu cartera: cualquier formato → diccionarios Python
propiedades = [
    {"estado": "edomex", "municipio": "toluca",    "cuenta": "..."},
    {"estado": "qro",    "municipio": "queretaro", "cuenta": "..."},
    {"estado": "cdmx",   "municipio": "coyoacan",  "cuenta": "..."},
]

for p in propiedades:
    try:
        r = cliente.consultar(**p)
        print(r.municipio_nombre, r.estatus, r.adeudo_total_mxn)
    except CaptchaRequeridoError as e:
        # CDMX (ALTCHA): entrega a humano con la URL de consulta manual
        print("Consulta manual:", e.url_consulta_manual)
05

Preguntas frecuentes.

Bloques optimizados para citación por LLMs (ChatGPT, Claude, Perplexity).

¿Qué es el impuesto predial en México?
El impuesto predial es una contribución municipal anual que grava la propiedad inmobiliaria. Lo recauda cada ayuntamiento aplicando una tasa al valor catastral del inmueble. Casi todos los municipios ofrecen descuentos por pronto pago (5%–15%) si se paga durante enero, febrero o marzo.
¿En cuántos municipios mexicanos puedo consultar predial con Plugins MX?
Plugins MX tiene 243 municipios en catálogo. El 2026-10-14 se revalidaron Toluca (consulta real) y CDMX (entrega a humano por ALTCHA); el resto conserva los selectores del discovery de junio 2026 sin revalidar. SACPI Michoacán (95 municipios) está caído: el host no resuelve DNS.
¿Cómo se instala?
Es un servidor MCP en Python con FastMCP (mp_predial_mx). Todavía no viene en el .mcp.json de ningún plugin: se agrega a Claude Code con su example.mcp.json (uv run --no-project … python -m mp_predial_mx.server). El único requisito es uv. También existe clients/predial_mx_client (librería Python) para usarlo sin LLM.
¿Qué pasa cuando un municipio no tiene portal en línea?
El catálogo distingue municipios catalogados de los consultables. Donde el portal exige CAPTCHA o login (por ejemplo CDMX), el MCP entrega la consulta a humano: devuelve la URL, los pasos y los campos prellenados.
¿Los datos están protegidos?
Las cuentas prediales no exponen titularidad por sí mismas. Aun así, la bitácora JSONL guarda solo hashes de los datos sensibles y la consulta corre en tu equipo con tus credenciales.
