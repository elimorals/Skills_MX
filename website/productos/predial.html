02

Tools expuestas.

4 tools MCP invocables desde Claude Code, Cursor, o como librería Python pura (predial_mx_client).

→

predial_consultar

Consulta adeudo de una propiedad. Auto-routing: catálogo directo · SACPI · Mérida-dirección · Puebla-captcha.

predial_consultar(estado, municipio, cuenta_predial, [tipo, direccion])
→

predial_listar_municipios

Lista municipios del catálogo. Filtro opcional por estado o por solo_validados=True.

predial_listar_municipios([estado], [solo_validados])
→

predial_buscar_municipio

Busca municipio por nombre fuzzy. Devuelve mejores coincidencias con su configuración.

predial_buscar_municipio(query)
→

predial_estadisticas_catalogo

Devuelve stats del catálogo (total muns, validados, con captcha, plataformas SaaS detectadas).

predial_estadisticas_catalogo()

Cómo se ve el código.

cartera_predial.py 
from predial_mx_client import PredialClient
import openpyxl

cliente = PredialClient()

# Tu cartera: cualquier formato → diccionarios Python
propiedades = [
    {"alias": "Casa Coyoacán",
     "estado": "CDMX",
     "municipio": "Coyoacán",
     "cuenta": "123-456-789"},

    {"alias": "Depa Zapopan",
     "estado": "JAL",
     "municipio": "Zapopan",
     "cuenta": "GDL-0001-22"},

    {"alias": "Rancho SACPI",
     "estado": "MICH",
     "municipio": "Ciudad Hidalgo",
     "cuenta": "MICH-7788"},
]

# Consulta en paralelo — auto-routing transparente
resultados = cliente.consultar_lote(propiedades)

# Exporta a Excel listo para mandar
wb = openpyxl.Workbook()
ws = wb.active
ws.append(["Propiedad", "Adeudo", "Vence", "Estado"])
for r in resultados:
    ws.append([r.alias, r.adeudo, r.vencimiento, r.estatus])
wb.save("cartera-predial-2026-06.xlsx")

print(f"Total cartera: ${sum(r.adeudo for r in resultados):,.2f} MXN")
# Total cartera: $27,912.50 MXN
