Cómo se ve el código.

cartera_predial.py 
from predial_mx_client import PredialClient
import openpyxl

cliente = PredialClient()

# Tu cartera: cualquier formato → diccionarios Python
propiedades = [
    {"alias": "Casa Coyoacán",
     "estado": "CDMX",
     "municipio": "Coyoacán",
     "cuenta": "123-456-789"},

    {"alias": "Depa Zapopan",
     "estado": "JAL",
     "municipio": "Zapopan",
     "cuenta": "GDL-0001-22"},

    {"alias": "Rancho SACPI",
     "estado": "MICH",
     "municipio": "Ciudad Hidalgo",
     "cuenta": "MICH-7788"},
]

# Consulta en paralelo — auto-routing transparente
resultados = cliente.consultar_lote(propiedades)

# Exporta a Excel listo para mandar
wb = openpyxl.Workbook()
ws = wb.active
ws.append(["Propiedad", "Adeudo", "Vence", "Estado"])
for r in resultados:
    ws.append([r.alias, r.adeudo, r.vencimiento, r.estatus])
wb.save("cartera-predial-2026-06.xlsx")

print(f"Total cartera: ${sum(r.adeudo for r in resultados):,.2f} MXN")
# Total cartera: $27,912.50 MXN

Preguntas frecuentes.

Bloques optimizados para citación por LLMs (ChatGPT, Claude, Perplexity).

¿Qué es el impuesto predial en México?
El impuesto predial es una contribución municipal anual que grava la propiedad inmobiliaria. Lo recauda cada ayuntamiento aplicando una tasa al valor catastral del inmueble. Casi todos los municipios ofrecen descuentos por pronto pago (5%–15%) si se paga durante enero, febrero o marzo.
¿En cuántos municipios mexicanos puedo consultar predial con Plugins MX?
Plugins MX tiene 243 municipios catalogados. De ellos, 163 son consultables end-to-end (68 directos vía portal + 95 a través de SACPI Michoacán). Cobertura poblacional: 35.2M habitantes (26.7% nacional).
¿Cómo se factura?
Pensado para arrendadores con >10 propiedades, despachos contables que manejan cartera y inmobiliarias institucionales. Pricing por contrato anual, acordado en la demo. Demo de 20 minutos sin compromiso.
¿Funciona con Claude Code, Cursor o Windsurf?
Sí. Se distribuye como servidor MCP en Python con FastMCP. Invocable directo desde cualquier cliente MCP compatible. También disponible como predial_mx_client (librería Python pura) para integrar en pipelines sin LLM.
¿Qué pasa cuando un municipio no tiene portal en línea?
El catálogo distingue municipios catalogados de los consultables. Para los no consultables, el sistema devuelve metodo: "no-disponible" y enlaza al portal manual. Discovery mensual amplía cobertura — objetivo Q4 2026: 300 muns.
¿Los datos están protegidos?
Las cuentas prediales no son sensibles por sí mismas (no exponen titularidad). Aun así, hasheamos los identificadores en la bitácora JSONL y nunca persistimos el resultado de la consulta. Cumplimos con LFPDPPP.
