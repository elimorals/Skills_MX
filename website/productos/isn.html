01

Una idea simple.

"Cambiar la nómina de Jalisco a Yucatán ahorra 17% de ISN. Saberlo en segundos vs descubrirlo en una junta."
02

5 tools expuestas.

La primera (isn_calcular) funciona offline desde catálogo — no toca ningún portal. Útil para asesoría fiscal sin credenciales del cliente.

★

isn_calcular

Calcula ISN del periodo aplicando la tasa del estado. Offline-first: no requiere credenciales.

isn_calcular(nomina_gravable: float, estado: str)
→

isn_listar_estados

Lista los 32 estados con su configuración: tasa, portal, vencimiento, validado sí/no.

isn_listar_estados([solo_validados])
→

isn_info_estado

Detalle completo de un estado: URL portal, selectores DOM documentados, requiere e.firma sí/no.

isn_info_estado(estado)
→

isn_generar_linea_captura

Línea de captura para pago referenciado. Path real requiere credenciales del estado.

isn_generar_linea_captura(estado, periodo, rfc, nomina_gravable)
→

isn_descargar_declaracion

PDF de la declaración del periodo desde la bóveda estatal. Cache 90 días.

isn_descargar_declaracion(estado, periodo, rfc)

04

Cómo se ve el código.

comparativo_isn.py 
from mp_isn_mx import IsnMxClient

cliente = IsnMxClient()
nomina = 500_000  # MXN gravables mensuales

# Comparativo entre 4 estados en milisegundos — offline
for estado in ["CDMX", "JAL", "GTO", "BC"]:
    r = cliente.calcular(nomina, estado)
    print(f"{r['estado']:<20} {r['tasa_pct']}% → ${r['isn_a_pagar']:,.2f}")

# Ciudad de México       3.0% → $15,000.00
# Jalisco                3.0% → $15,000.00
# Guanajuato             2.0% → $10,000.00   ← 33% ahorro
# Baja California        1.8% → $ 9,000.00   ← 40% ahorro

# Genera línea de captura del mes
linea = cliente.generar_linea_captura(
    estado="CDMX",
    periodo="2026-05",
    rfc="ABC120101AB1",
    nomina_gravable=nomina,
)
print(f"Pagar ${linea['monto_a_pagar']} con línea {linea['linea_captura']}")
