Solución: isn_calcular() + isn_generar_linea_captura() en bulk. Dashboard con semáforo de vencimientos. Cron diario que avisa al cliente por WhatsApp.

Solución: cartera-predial-multi-municipio.workflow.js consulta los 60 inmuebles en paralelo. Excel con totales, vencimientos y ranking listo en < 5 minutos.

07

Cómo se ve en práctica.

i.

Setup en una tarde

Clonas el repo, corres install-hooks.sh, declaras tus credenciales en .env. Sin credenciales, los MCPs de portales públicos consultan en vivo y los de APIs privadas responden datos marcados simulated: true.

ii.

Conectas a Claude o a tu stack

Cada MCP es invocable desde Claude Code, Cursor, Windsurf, o consumible como librería Python pura (clients/predial_mx_client).

iii.

Construyes workflows

Combinas MCPs en archivos .workflow.js con phase() / parallel() / pipeline(). 26 archivos .workflow.js — incluido declaracion-resico-mensual con human-in-loop WhatsApp.

iv.

Operas con confianza

Los tests live (PLUGINS_MX_LIVE=1) avisan cuando un portal cambia o deja de responder. Bitácora JSONL audita cada llamada.

ejemplo: cartera predial multi-municipio 
from mp_predial_mx import PredialClient

cliente = PredialClient()
propiedades = [
    {"municipio": "Coyoacán", "cuenta": "123-456-789"},
    {"municipio": "Zapopan",  "cuenta": "GDL-0001-22"},
    {"municipio": "Ciudad Hidalgo", "cuenta": "MICH-7788"},
]

resultados = [cliente.consultar(**p) for p in propiedades]
# ↳ Auto-routing: CDMX directo · Zapopan directo · Michoacán vía SACPI

total = sum(r.adeudo for r in resultados)
print(f"Cartera total: ${total:,.2f} MXN")
# Cartera total: $27,912.50 MXN
