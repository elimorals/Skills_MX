02 · ONBOARDING · PILOTO 30 DÍAS

Día por día. Sin sorpresas.

Después de firmar el SOW del piloto, esto es lo que pasa cada semana. Cuatro semanas. Un vertical funcionando en producción. Entregables medibles cada viernes.

SEMANA 01 · DÍAS 1-7

Kickoff y alcance.

Decidimos qué vertical es el primero.

Lunes: reunión de kickoff por Google Meet (90 min). Defines qué problema duele más hoy: cartera predial, validación REPSE, ISN multi-estado, o algo específico de tu giro. Acordamos el alcance escrito en un SOW de máximo 2 páginas que ambos firmamos al final de la semana.

  • Diagnóstico del flujo manual actual (qué se hace hoy y cuánto tarda)
  • Selección de los 1-3 MCPs que más mueven la aguja
  • Definición de éxito: métricas concretas (ej. "consultar 50 propiedades en <3min")
  • Lista de credenciales que tendrás que generar (sin compartirme aún)
Entregable viernes SOW firmado por ambos · Roadmap visual con hitos por semana · Lista de credenciales que necesitarás generar antes del lunes
SEMANA 02 · DÍAS 8-14

Setup técnico.

Instalo Plugins MX en tu infraestructura.

Te entrego un contenedor Docker y la configuración para Claude Code o tu cliente MCP. Si el plan incluye path real Playwright, ese contenedor corre en TU servidor — tus credenciales nunca tocan mi infra. Yo solo veo respuestas mock.

  • Docker container plugins-mx:3.59 en tu VPS, on-prem o cloud
  • Configuración de variables de entorno con tus credenciales (las pones tú)
  • Conexión MCP probada desde Claude Code o tu cliente
  • Primer health-check que confirma que los 76 portales responden
  • Bitácora hasheada habilitada (compatible LFPDPPP)
Entregable viernes Container corriendo en tu infra · Conexión MCP probada · 1 consulta real ejecutada exitosamente · Documento de runbook básico
SEMANA 03 · DÍAS 15-21

Workflows + integración.

Conectamos los MCPs a tu proceso real.

Construimos el primer workflow Claude Agent SDK que combina los MCPs elegidos con tu sistema (ERP, CRM, hoja de cálculo, lo que sea). Sesión técnica de 2-3 horas con tu equipo IT o el contador titular.

  • 1 workflow productivo conectado a tu stack actual
  • Output configurado (Excel, PDF firmable, payload JSON a tu API, lo que necesites)
  • Cron para que corra automáticamente (diario/semanal/mensual)
  • Alertas WhatsApp/Email cuando algo necesita atención humana
  • Capacitación 2h con tu equipo operativo (3-8 personas)
Entregable viernes Workflow productivo corriendo en automático · Tu equipo capacitado · 1 reporte real generado contra datos de tu cartera actual
SEMANA 04 · DÍAS 22-30

Producción + decisión.

El sistema corre solo. Tú decides si firmas anual.

Una semana de operación real con tu volumen completo. Yo monitoreo de cerca pero no intervengo salvo que algo se rompa. Al día 28 nos sentamos a revisar: ¿se cumplieron las métricas del SOW? ¿el equipo lo está usando? ¿vale la pena renovar?

  • Operación real sin mi intervención directa
  • Métricas de uso reales (cuántas consultas, cuánto tiempo ahorrado, errores detectados)
  • Sesión de revisión día 28: lecciones aprendidas + comparativa contra SOW inicial
  • Propuesta de contrato Producción anual (si tiene sentido para ambos)
  • Opción de cerrar limpiamente sin renovar — sin presión, sin penalización
Entregable día 30 Reporte ejecutivo del piloto · Métricas reales vs SOW · Decisión clara: firmar Producción, ajustar alcance, o cerrar sin renovar

Credenciales que vas a generar.

Estas las tramitas tú directamente con cada autoridad. Yo nunca veo los archivos ni las contraseñas — solo te indico exactamente qué generar y dónde ponerlo dentro del contenedor Docker.

e.firma SAT (FIEL)

SAT.gob.mx · presencial o renovación digital

Archivos .cer + .key + contraseña. Vigencia 4 años. Necesario para Buzón Tributario, descarga masiva CFDI, declaraciones e histórico.

RFC + CIEC SAT

SAT.gob.mx/personas/iniciar-sesion

Usuario + contraseña de 8 caracteres. Necesario para consultas básicas del padrón, descarga CSF, agendar citas.

NPIE IMSS

IMSS Desde Su Empresa (IDSE)

Número Patronal de Identificación Electrónica con tarjeta física + PIN. Permite SUA, movimientos afiliatorios, EMCR, cédulas.

Usuario INFONAVIT Empresarial

Portal Empresarial INFONAVIT

Usuario + contraseña del responsable patronal. Permite EMIS, descuentos por trabajador, créditos vigentes, avisos.

API keys de tus pasarelas de pago

Mercado Pago / Conekta / Stripe / etc.

Tokens production o sandbox según el alcance del piloto. Lectura de transacciones, no movimientos de fondos.

Llave MX (opcional)

llave.gob.mx

Necesaria solo si el vertical involucra trámites federales ciudadanos (becas, INE, salud pública). SSO 8h.
